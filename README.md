# myproject OAuth website

A minimal static homepage and privacy policy for a privately operated Google Calendar integration.

## Files
- `index.html`: public homepage
- `privacy.html`: public privacy policy
- `style.css`: shared styling

## Publishing
1. Review and correct the privacy statements to match the actual behavior of your application, including AI providers, storage, and retention.
2. Host the files on a public HTTPS static site.
3. In Google Auth Platform > Branding, add the homepage and privacy policy URLs, as required by your app configuration.
4. Follow any Google domain ownership or app verification requests; publishing may require more than these pages.

Do not upload OAuth secrets, calendar data, server addresses, or tokens. The name `myproject` is generic branding, not a claim that the application has no external data processing.
