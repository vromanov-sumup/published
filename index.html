Personal-use application

myproject

A privately operated application for managing personal scheduling information.

What it does

With the account owner's authorization, myproject uses the Google Calendar API to view calendar information and create, update, or delete events in response to the owner's requests.

Why calendar access is requested

Calendar access is used to help the owner view and manage their schedule. This application is not a public service and does not offer public registration.
